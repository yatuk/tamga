# Pilot Program

Tamga runs a design-partner pilot for teams in regulated industries
evaluating pre-production LLM security controls.

## What you get

- Guided staging deployment (Docker Compose or Helm)
- Custom entity tuning for your regulated data types (customer IDs, account
  formats, internal document numbers)
- Compliance mapping pack (KVKK, BDDK, GDPR) tailored to your controls
- Direct maintainer support during the evaluation
- Roadmap input — pilot feedback shapes what ships next

## What we ask

- A 2-4 week evaluation window
- Anonymized detection and latency metrics from your environment
- A short feedback session at the end
- Optional: a reference or case study if the results warrant it
