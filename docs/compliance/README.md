# Compliance mappings

> This page is not legal advice. It shows which Tamga controls are relevant
> to which requirement. Whether an organisation complies depends on its own
> processes and on an assessment by a qualified person.

The pages below show which Tamga controls are relevant to which requirement
of each framework. The controls, the request log and the hash-chained audit
log can be used as evidence in an assessment. The controls apply only to
traffic that is routed through the proxy.

- [KVKK](kvkk.md): Turkish Data Protection Law, articles 4-13
- [BDDK](bddk.md): Turkish Banking Regulator, information systems regulation
- [GDPR](gdpr.md): EU General Data Protection Regulation
- [OWASP LLM Top 10](owasp-llm-top-10.md): coverage matrix and gap analysis
